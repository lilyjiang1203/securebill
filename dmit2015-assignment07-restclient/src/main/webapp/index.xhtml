SECURE BILLING DEMO

SecureBill

A secure billing application demonstrating role-based access control, JWT authentication, and multi-tenant data isolation.

Role-Based Access

Bill operations are protected with role-specific permissions for reading, creating, updating, and deleting records.

Multi-Tenant Data

Authenticated users can manage their own billing data while remaining isolated from other users' records.

Secure Authentication

Authentication is handled by Keycloak, while JWT tokens are validated by secured Jakarta REST API endpoints.

Keycloak · MicroProfile JWT · Jakarta EE

Project Architecture

Jakarta Faces · PrimeFaces · REST APIs · Keycloak · MicroProfile JWT · WildFly
